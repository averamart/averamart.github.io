# Avera Mart — বিজনেস ম্যানেজার অ্যাপ

একটি সম্পূর্ণ ফ্রন্ট-এন্ড (HTML/CSS/JS) বিজনেস ম্যানেজমেন্ট অ্যাপ — প্রোডাক্ট, অর্ডার, ক্রয়, খরচ, লাভ-ক্ষতি ও ইনভয়েস ম্যানেজ করার জন্য। কোনো সার্ভার/হোস্টিং খরচ ছাড়াই Netlify বা GitHub Pages-এ ফ্রি হোস্ট করা যাবে।

## যা যা আছে
- ৩টি রোল: Admin, Manager, Delivery Man — প্রতিটির আলাদা এক্সেস
- Manager ও Delivery Man-এর স্ক্রিনে ক্রয়মূল্য (Cost Price) ও নিট প্রফিট সম্পূর্ণ লুকানো
- কাস্টমার টাইপ (সাধারণ/শেয়ারহোল্ডার) সিলেক্ট করলেই দাম স্বয়ংক্রিয়ভাবে বসে যায়
- অর্ডার "Delivered" হলেই কেবল স্টক বিয়োগ হয় (Pending/Processing অবস্থায় স্টক অপরিবর্তিত থাকে)
- কম স্টকের পণ্যের জন্য ড্যাশবোর্ডে সতর্কবার্তা
- ব্র্যান্ডেড ইনভয়েস — প্রিন্ট (সাধারণ ও থার্মাল সাইজ দুই ভাবেই) এবং হোয়াটসঅ্যাপে শেয়ার করার বাটন
- শেয়ারহোল্ডার লভ্যাংশ স্বয়ংক্রিয় হিসাব (হার সেটিংস থেকে পরিবর্তনযোগ্য)

## ☁️ ক্লাউড ডেটাবেজ (Firebase) — বাধ্যতামূলক সেটআপ
এই ভার্সনে ডেটা আর ব্রাউজারে আটকে থাকে না — **Firebase Firestore** ক্লাউড ডেটাবেজে জমা হয়। তাই Admin, Manager ও Delivery Man আলাদা আলাদা ফোন/কম্পিউটার থেকে লগইন করলেও সবাই একই ডেটা দেখবে ও রিয়েল-টাইমে আপডেট পাবে (কেউ একজন অর্ডার "Delivered" করলে অন্যরাও সাথে সাথে দেখতে পাবে, পেইজ রিফ্রেশ করা লাগবে না)।

**অ্যাপ চালু করার আগে অবশ্যই করতে হবে:**
1. `firebase-config.js` ফাইলটি খুলুন।
2. Firebase Console থেকে পাওয়া আপনার নিজের প্রজেক্টের `firebaseConfig` মানগুলো বসান (নিচের ধাপগুলো অনুসরণ করুন)।
3. এই ফাইল ছাড়া অ্যাপ কোনো ডেটা লোড/সেভ করতে পারবে না — লগইন স্ক্রিনে "ক্লাউড ডেটাবেজের সাথে সংযোগ করা হচ্ছে..." লেখাটা আটকে থাকবে।

### Firebase সেটআপের ধাপ
1. **প্রজেক্ট তৈরি:** firebase.google.com → Add project → নাম দিন (যেমন `avera-mart`) → Create project।
2. **Firestore চালু করুন:** বাম মেনু → Build → Firestore Database → Create database → কাছাকাছি একটা রিজিওন বেছে "Start in test mode" দিয়ে Enable করুন।
3. **Anonymous লগইন চালু করুন:** Build → Authentication → Get started → Sign-in method ট্যাবে "Anonymous" এনাবল করে Save করুন।
4. **Web App রেজিস্টার করুন:** প্রজেক্ট Overview পেইজে `</>` (Web) আইকনে ক্লিক করে একটা নাম দিন। এরপর দেখানো `firebaseConfig` অবজেক্টটা কপি করুন।
5. **Security Rules বসান:** Firestore Database → Rules ট্যাবে গিয়ে নিচের কোডটা বসিয়ে Publish করুন:
   ```
   rules_version = '2';
   service cloud.firestore {
     match /databases/{database}/documents {
       match /averamart/{doc} {
         allow read, write: if request.auth != null;
       }
     }
   }
   ```
6. **Config ফাইলে পেস্ট করুন:** `firebase-config.js` ফাইলে ৪ নম্বর ধাপে কপি করা মানগুলো বসান।

### একটা জরুরি নিরাপত্তা নোট
উপরের Security Rules-এ শুধু বলা আছে "অ্যাপ থেকে সাইন-ইন করা যেকোনো ডিভাইস" পড়তে/লিখতে পারবে — এটা Admin/Manager/Delivery রোলের পার্থক্য বোঝে না (রোল-ভিত্তিক নিয়ন্ত্রণ এখন শুধু অ্যাপের ভেতরের UI-তে, ডেটাবেজ লেভেলে না)। অর্থাৎ যদি অ্যাপের লিংক ও এই কোড কোনোভাবে অপরিচিত কারো হাতে যায়, সে চাইলে ব্রাউজারের ডেভেলপার টুল দিয়ে সরাসরি ডেটাবেজে প্রবেশ করার চেষ্টা করতে পারে। ছোট পরিসরের বিশ্বস্ত টিমের জন্য এটি যথেষ্ট, তবে লিংকটা শুধু আপনার নিজের স্টাফদের সাথেই শেয়ার করুন। ব্যাংক-গ্রেড নিরাপত্তা দরকার হলে সেটা পরবর্তী একটা আপগ্রেড ধাপ হতে পারে।

## হোয়াটসঅ্যাপ ও থার্মাল প্রিন্টার সম্পর্কে
- **হোয়াটসঅ্যাপ শেয়ার:** বাটনে ক্লিক করলে হোয়াটসঅ্যাপ খুলে যাবে এবং ইনভয়েসের তথ্য মেসেজ হিসেবে বসানো থাকবে (কাস্টমারের নম্বর অটো-ফিল হবে)। এটি ফ্রি এবং কোনো API কী লাগে না। পিডিএফ ফাইল অটোমেটিক অ্যাটাচ হওয়ার সুবিধা ব্রাউজার থেকে সরাসরি সম্ভব না — চাইলে প্রিন্ট বাটনে "Save as PDF" করে সেটি ম্যানুয়ালি হোয়াটসঅ্যাপে অ্যাটাচ করে দিতে হবে।
- **থার্মাল প্রিন্ট:** "থার্মাল প্রিন্ট" বাটনে ক্লিক করলে ইনভয়েসটি ছোট (৫৮/৮০mm) সাইজে ফরম্যাট হয়ে প্রিন্ট ডায়ালগ খুলবে — আপনার ব্লুটুথ/USB থার্মাল প্রিন্টার যদি কম্পিউটারে ডিফল্ট প্রিন্টার হিসেবে সেট করা থাকে, তাহলে এখান থেকেই প্রিন্ট হয়ে যাবে।

## Netlify-তে ফ্রি ডিপ্লয় করার নিয়ম (সবচেয়ে সহজ পদ্ধতি)
1. [netlify.com](https://www.netlify.com) এ গিয়ে ফ্রি অ্যাকাউন্ট খুলুন।
2. লগইন করার পর ড্যাশবোর্ডে **"Add new site" → "Deploy manually"** এ ক্লিক করুন।
3. এই ফোল্ডারের ভেতরের সবগুলো ফাইল (index.html, style.css, app.js, assets ফোল্ডার) সিলেক্ট করে সরাসরি ড্র্যাগ-অ্যান্ড-ড্রপ করুন।
4. কয়েক সেকেন্ডেই একটি লিংক (যেমন `https://averamart.netlify.app`) পেয়ে যাবেন — এটাই আপনার লাইভ অ্যাপ।
5. চাইলে Site settings থেকে সাইটের নাম পরিবর্তন করে নিজের পছন্দমতো সাবডোমেইন বসাতে পারবেন।

## GitHub Pages-এ ফ্রি ডিপ্লয় করার নিয়ম
1. GitHub-এ একটি নতুন Repository তৈরি করুন (যেমন `avera-mart-app`)।
2. এই ফোল্ডারের সব ফাইল আপলোড করুন (GitHub ওয়েবসাইট থেকে "uploading an existing file" অপশন দিয়েও করা যায়, Git কমান্ড জানার দরকার নেই)।
3. Repository-এর **Settings → Pages** এ যান।
4. "Branch" থেকে `main` সিলেক্ট করে Save করুন।
5. কিছুক্ষণ পর `https://<আপনার-ইউজারনেম>.github.io/avera-mart-app/` লিংকে অ্যাপটি লাইভ হয়ে যাবে।
